# Changelog

## 1.0.2

- Buttons and count badges (activity bar, panels, extensions) are now a deep aurora teal with white text. The small dark text on the bright cyan was hard to read.

## 1.0.1

- The paused line while debugging is now a dark amber, so it no longer looks the same as find matches. Every code color on it stays at 4.5:1 or more.

## 1.0.0

- First release. Generated from the same palette as the Visual Studio 2026 and Zed versions of Kyokko.
